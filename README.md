## Recent projects 🛠️

### Libraries

| Project | What it is |
|---|---|
| [autodyne](https://github.com/vaibhav-gopal/autodyne) | Numerics for signals, processes and systems in Rust: DSP, linear algebra, statistics and differentiable programs, built to outrun NumPy / SciPy |
| sylva *(private for now)* | Graphs and trees that remember: general-purpose structures with a versioned op log on top |
| parda *(private for now)* | A plug-and-play 2D UI and graphics toolkit for Rust: one retained tree, animation-first, 2.5D depth, text, vectors and widgets, inside any host |
| kaatchi *(private for now)* | A real-time 3D renderer for Rust: PBR, cascaded shadows, clustered lighting, GPU-driven, engine-embeddable |
| [torii](https://github.com/vaibhav-gopal/torii) | A cross-platform game engine and graphics visualization API |
| weft *(private for now)* | A schema language and compiler: one schema for the wire format, PostgreSQL migrations and service code in Rust, TypeScript, Python and C++ |

### Applications

| Project | What it is |
|---|---|
| woodshed *(private for now)* | A self-hosted sheet music library and practice trainer: scores, annotations, skill tracking and drills, offline on every device |
| camelot *(private for now)* | Music library organization, curation, review and playback over pluggable streaming providers |
| tend *(private for now)* | Every project's design kept in its repo as signed history, given to coding agents through one set of tools |
